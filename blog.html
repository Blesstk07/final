Comment j’ai commencé le développement web

En 2e année de dev web à l'Université Protestante au Congo, après Boboto. Autodidacte via tutos Graven (HTML/CSS/JS)/Java, sans fond tech. Persévère malgré manque de motivation et peur du public, pour opportunités remote/freelance

Mes outils préférés pour coder

VS Code, GitHub, extensions et workflow personnel pour rester productif et organisé.

Pourquoi j’aime le design web

Créer des interfaces modernes, propres et fluides est une passion que j’applique dans tous mes projets.

Mes projets personnels préférés

Pour voir mes projets concrets et ce que j'en ai appris, direction mon compte GitHub – c'est là que tout est!

Comment j’apprends de nouveaux langages

Ma méthode: théorie rapide via tutos YouTube (Graven), notes actives, exercices pratiques et mini-projets perso pour tester les bases.

Mes erreurs et comment je les corrige

Erreurs fréquentes: syntaxe oubliée, copier-coller sans comprendre, ignorer les bases. Solutions: vérifier code ligne par ligne, console.log et refaire tutos pour consolider les bases.

Mes sources d’inspiration

Développeurs: Graven et FaizDev pour leurs tutos clairs. Plateformes: YouTube et freeCodeCamp pour pratiquer et rester motivé.

Comment je reste motivé

Alternance tutos et pauses fun (jeux/musique), mini-objectifs quotidiens et récompenses pour garder motivation et éviter burnout.

Mes astuces pour organiser mon temps

Bloc-notes pour 2-3 tâches essentielles, travail post-cours, loisirs pour décompresser et flexibilité pour éviter le stress.

Mes conseils pour débutants

Commence par HTML/CSS/JS via tutos simples, pratique directe avec petits projets, debug avec console.log, et persévère malgré la motivation faible.
